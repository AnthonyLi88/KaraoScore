# KaraoScore
Turn your computer into a karaoke machine!

## Vision
Our vision is to make a web app that gamifies your singing. You submit either an audio file or link to a song and another of the instrumentals (technically can be used with any audio file if you wanted), and you will be put into a virtual karaoke room where you sing into a microphone. 

After you’ve finished singing, your singing will be combined with the instrumental track and compared to the original track. 

## Getting Started
1. **Download an IDE**: Any IDE will work including Visual Studio Code, Sublime Text, etc.
2. **Download Git (if you haven't)**: Download here: https://git-scm.com/downloads. 
3. **Set up Git**: Follow the instructions [here](https://docs.github.com/en/get-started/getting-started-with-git/set-up-git) and complete steps 2, 3 and authenticating with GitHub from Git.
4. Create a new folder for your project. 
5. In terminal, change directory(cd) to the new folder and type the following: 
```bash
   git clone https://github.com/AnthonyLi88/KaraoScore
   cd KaraoScore
   npm install
```
6. Start the app in the `dev` environment:
```bash
npm start
```

## Packaging for Production

To package apps for the local platform:

```bash
npm run package
```
